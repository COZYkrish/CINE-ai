How It Works

The interface stays simple, but the recommendation flow uses multiple machine learning steps under the hood.

TF-IDF Vectorization

Movie metadata like cast and director are converted into weighted text vectors. Important names get stronger weights, while common words contribute less.

Cosine Similarity

CineAI compares the angle between movie vectors to measure similarity. Smaller angles mean stronger content similarity between the selected movie and candidate titles.

K-Means Clustering

Movies are grouped into clusters with similar feature patterns. Recommendations can then be prioritized from the same cluster before using broader similarity fallback matches.
